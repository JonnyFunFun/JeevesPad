# JeevesPad Manager

Manage every [Jeeves](https://github.com/JonnyFunFun/JeevesPad) wall panel (wallPad) from Home Assistant:

- See every wallPad at a glance: online, battery, screen brightness, idle time
- Edit each wallPad's settings and dashboards (Home cards, rooms, card names and sizes)
- Copy settings from one wallPad to others
- Identify a wallPad, send it Home, set its brightness
- Install and update Jeeves over SSH, restart it, reboot the iPad, read its logs
- Set up a newly jailbroken iPad: installs Jeeves and adds it to your fleet

Pair it with the **JeevesPad** integration (installable with HACS) to get each wallPad as a Home Assistant device with battery, brightness and action entities.
